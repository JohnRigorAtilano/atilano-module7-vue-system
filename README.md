# 📚 ATILANO LIBRA — Library Management System

A modern and responsive Library Management System developed using **Vue.js 3 and Vite** for Module 7.

The system provides a high-tech dashboard for managing library book records with CRUD operations, search functionality, local storage, responsive design, and GitHub Pages deployment.

## ✨ Features

- 📊 Modern library dashboard
- 📚 Add new book records
- ✏️ Edit existing book records
- 🗑️ Delete book records
- 🔍 Search and filter books
- 💾 LocalStorage data persistence
- 📈 Automatic library statistics
- 🏷️ Book categories and book status
- 🌙 Dark/light interface
- 📱 Responsive mobile layout
- ☰ Responsive sidebar navigation
- ⚡ Vue.js interface
- 🌐 GitHub Pages deployment
